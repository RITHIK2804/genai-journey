# RithikGPT v1 - Conversational Chatbot

## Overview

RithikGPT v1 is my first end-to-end Generative AI project built using Python, Streamlit, and the Google Gemini API.

## Features

* ChatGPT-style interface
* Conversation memory
* Gemini API integration
* Streamlit web application
* Multi-turn conversational chatbot

## Tech Stack

* Python
* Streamlit
* Google GenAI SDK

## Workflow

User Input → Store in Session State → Convert Chat History → Send to Gemini API → Generate Response → Display Response → Save Response

## What I Learned

* Streamlit basics
* Gemini API integration
* Session state management
* Conversation history
* Prompt formatting
* Debugging API and UI issues

## Challenges Faced

* Invalid API key
* Blank Streamlit page
* Gemini model overload (503 error)

## Status

Completed
